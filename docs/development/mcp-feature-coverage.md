## Verification limits

Canonical operation IDs, aliases, scope metadata and write verification are checked by the inventory. Fixed project queries and child-reference checks have unit coverage, and the PostgreSQL suite checks real native schemas and representative delegation flows. Static availability does not prove that every provider integration is configured, every generated answer is correct, or every runner/browser is reachable.
