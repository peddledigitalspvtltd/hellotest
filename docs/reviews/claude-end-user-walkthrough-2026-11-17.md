# Claude end-user walkthrough, architecture review and delivery plan

Implementation follow-up: see the [current gap implementation ledger](walkthrough-gap-implementation-2026-11-17.md) for source, validation and deployment receipts. The walkthrough results and proposed decisions below retain the original observations; their approval boundaries are historical.

Date: 17 November 2026. Target: `http://localhost:8080`, signed in as the authorized Admin User. Walkthrough project: `claude` / `claudeuser` (PROJ-8, `62fc066a-2ca4-4a99-be32-f613bc501861`).

Status: all 25 requested tasks were exercised; **Task 7 (AI grooming) did not complete**. Four narrow fixes are in the working tree with tests. **They are not deployed and not committed.** Everything else is a proposal for review.

A parallel walkthrough of the same tasks is in [codex-end-user-walkthrough-2026-11-17.md](codex-end-user-walkthrough-2026-11-17.md). Where both walkthroughs found the same thing, its ID is given in brackets, so independent confirmation is visible. Findings that only one of us made are marked as such.

## Verdict

1. **The workflow is complete and traceable.** Story, Sprint/Release, case, module, suite, run, defect, automation and health all connect, and every link I made was visible from the other end. A defect arrives pre-filled with its run, case, Story, Sprint and Release. This is the product's strength; the plan below must not trade it away.
2. **The weakness is trust in what the screens say.** One dataset produced four different "pass rate" figures (50%, 42%, 25%, 0%), two "readiness" figures (70% and a decision score of 53/100), and a run that reports 0 defects while two defects name it. Each figure follows its own formula; none is labelled as a different measure.
3. **AI failures hide their cause.** Four of five early Story generations ended in the same sentence, while the real causes were quota, network, time-out and incomplete output. Every failure was also reported on the first stage.
4. **Run setup makes people restate what the environment already knows,** and a data-set link that is rejected is dropped without a word.
5. **The walkthrough found real product gaps** (weak passwords, account disclosure, no lockout, no server-side e-mail format check). These need decisions as well as code.
6. **Structure.** 36 of the 40 source files over 1,200 lines sit outside the existing size gate, including a 59,982-line stylesheet and pages of 9,765 to 15,234 lines.
