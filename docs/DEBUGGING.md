# Debugging HelloTest

The current guide is the [development debugging runbook](development/debugging.md).

It covers API, frontend, TestEngine and native worker breakpoints; inspector ports; request/trace IDs; structured logs; queue diagnosis; and recovery that preserves data. Start with [CONTRIBUTE.md](../CONTRIBUTE.md) for the numbered setup, environment file, F5 profiles and first request walkthrough. Use [CONTRIBUTING.md](../CONTRIBUTING.md) for engineering standards and terminal workflows.

VS Code configurations remain in [launch.json](../.vscode/launch.json) with supporting [tasks.json](../.vscode/tasks.json). Inspect their local environment before starting a debugger compound.
