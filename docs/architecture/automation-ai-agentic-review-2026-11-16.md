## Implemented changes

- Six AI HTTP domain registrars replace the mixed router; authorization regression coverage includes repair, release decisions and assertion mapping.
- Automation owns browser pairing implementation, with a compatibility export for the existing agentic API.
- Automation step authoring and provider transport are separate modules, retaining native tool, retry, cancellation, private parameter and executable code behavior.
- Complete quality graph captures use the last complete inventory as their baseline.
- Protected browser startup/navigation diagnostics are now retained from the actual saved build failure path.
- Unused presentation wrappers were removed; archive metadata is ignored; compiler documentation paths were repaired.
- `npm run test:quality-persistence:postgres` creates a disposable local database, runs real PostgreSQL checks and drops it, including on failure. It makes no model-provider request.
